# Battleship: Space Edition

เกมเรือรบธีมอวกาศ 2–8 คน เล่นผ่านเว็บ สร้างห้องแล้วส่งรหัสหรือลิงก์ให้เพื่อน หรือเล่นกับบอท

## เมนูหน้าแรก

- **START GAME** ใส่ชื่อ แล้วสร้างห้องหรือเข้าห้องด้วยรหัส (ภาพยาน เมนู และกติกาจะซ่อน กด "กลับหน้าหลัก" เพื่อย้อนกลับ)
- **โหมดการเล่น** เลือกเล่นกับเพื่อน หรือเริ่มเกมกับบอท 1–7 ตัวทันที
- **ตั้งค่า** ชื่อผู้เล่น กระสุนและเวลาของห้องที่คุณสร้าง และเปิด/ปิดเอฟเฟกต์เคลื่อนไหว (บันทึกในเบราว์เซอร์)

## หน้าจอระหว่างเล่น

- **ช่วงสั่งยิง** กดเลือกคนที่จะโจมตี กระดานของคนนั้นจึงเปิดขึ้น เปลี่ยนคนได้ตลอด และกดคนเดิมซ้ำหรือ "หุบกระดาน" เพื่อปิด รายการเป้าที่เลือกไว้อยู่ในแถบด้านล่าง กดเพื่อยกเลิกได้
- **ช่วงเปิดคำสั่ง** แสดงทีละคนว่าใครกำลังยิงใคร พร้อมกระดานที่กำลังถูกยิง
- "กระดานของคุณ" "กระดานทั้งหมด" และ "บันทึกเกม" กดที่หัวข้อเพื่อกางหรือหุบ

## บอท

หัวห้องเพิ่มหรือนำบอทออกได้ในห้องรอ บอทตัดสินใจจากข้อมูลเดียวกับที่ผู้เล่นเห็น ไม่รู้ตำแหน่งยานที่ซ่อนอยู่

| ระดับ | วิธีเล่น |
| --- | --- |
| ง่าย | สุ่มยิง 1–3 ช่องต่อรอบ |
| เก่ง | คำนวณโอกาสโดนของทุกช่อง ตัวต่อตัวจะบุกหนัก ถ้าเล่นหลายคนจะยิงประหยัดและเล็งคนที่ยังแข็งแรง |

จากการจำลองบอทเล่นกันเองที่กระสุน 8 นัด: ตัวต่อตัวบอทเก่งชนะบอทง่ายราว 70% ส่วนวง 4–8 คนได้เปรียบเพียงเล็กน้อย (ราว 53–55% เมื่อมีสองระดับอย่างละครึ่ง)

## เปลี่ยนภาพหน้าแรก

ภาพยานเริ่มต้นคือ `public/img/hero.svg` ถ้าต้องการใช้ภาพของตัวเอง วางไฟล์ `hero.webp`, `hero.png` หรือ `hero.jpg` ไว้ในโฟลเดอร์ `public/img/` (สัดส่วนแนวนอนประมาณ 2:1) แล้วรีเฟรชหน้าเว็บ

## เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm start
```

เปิด http://localhost:3000 ส่วนเครื่องอื่นหรือมือถือในวง Wi-Fi เดียวกัน ใช้ที่อยู่ `http://<IP เครื่องนี้>:3000` ที่แสดงในหน้าต่างคำสั่งตอนเปิดเซิร์ฟเวอร์ (Windows อาจถามให้อนุญาต Node.js ผ่าน Firewall)

เปลี่ยนพอร์ต (PowerShell): `$env:PORT=8080; npm start`

## กติกา

- คนละ 1 กระดาน 5×5 (แถว A–E, คอลัมน์ 1–5) มีเรือ 4 ลำ ขนาด 3, 2, 1, 1 ช่อง วางชิดกันได้
- **ช่วงสั่งยิง** ทุกคนเลือกช่องบนกระดานคนอื่นแบบลับ จะยิงกี่นัดก็ได้ตามกระสุนที่มี หรือไม่ยิงเลยก็ได้
- **ช่วงเปิดคำสั่ง** เปิดทีละคน คนที่เปิดก่อนหมุนเวียนไปทุกรอบ
- **ยิงพลาด** กระสุนเป็นของเจ้าของกระดานทันที (ใช้ได้ในรอบถัดไป)
- **ยิงโดน** กระสุนหายไปจากเกม
- ช่องที่ถูกยิงไปก่อนแล้วในรอบเดียวกัน นับว่าพลาด
- เรือจมครบทุกลำ = ตกรอบ กระสุนที่มีหายไป และกระสุนที่ยิงพลาดใส่กระดานนั้นหลังจากนั้นก็หายไป
- คนที่ตกรอบระหว่างเปิดคำสั่ง คำสั่งที่เขียนไว้แล้วยังยิงตามปกติ
- คนสุดท้ายที่รอดชนะ
- ถ้ากระสุนหมดทุกคน หรือไม่มีใครยิง 3 รอบติด คนที่เหลือช่องเรือมากที่สุดชนะ (เท่ากันถือว่าเสมอ)

หัวห้องตั้งกระสุนเริ่มต้นได้ 1–10 นัด (ค่าเริ่มต้น 8 ถ้าตั้งต่ำมาก เกมจะจบเพราะกระสุนหมดก่อนมีใครจมครบ) และเวลาสั่งยิง 30/60/90/180 วินาที (ค่าเริ่มต้น 60) เมื่อหมดเวลา ระบบส่งช่องที่เลือกค้างไว้ให้ ช่วงวางเรือมีเวลา 120 วินาที ถ้ายังไม่กดพร้อมจะสุ่มวางให้

## การหลุดและกลับเข้าห้อง

- รีเฟรชหรือเน็ตหลุด กลับเข้าที่นั่งเดิมได้
- ในห้องรอ หลุดเกิน 30 วินาทีจะถูกนำออก
- ห้องที่ไม่มีใครออนไลน์ 10 นาทีจะถูกลบ
- เข้าห้องที่กำลังเล่นอยู่ไม่ได้ ต้องรอหัวห้องกด "เล่นอีกรอบ"

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
| --- | --- |
| `server/game.js` | กติกาและสถานะเกม |
| `server/index.js` | เว็บเซิร์ฟเวอร์ ห้อง socket และ timer |
| `server/bot.js` | การตัดสินใจของบอท |
| `public/shared.js` | กติกาการวางเรือ ใช้ทั้งสองฝั่ง |
| `public/app.js`, `public/styles.css` | หน้าจอผู้เล่น |
| `test/` | ชุดทดสอบ (`npm test`) |

## ข้อควรรู้เมื่อนำขึ้นอินเทอร์เน็ต

- ข้อมูลห้องอยู่ในหน่วยความจำ รีสตาร์ตเซิร์ฟเวอร์แล้วห้องหาย และรันได้ instance เดียว
- ต้องใช้โฮสต์ที่รัน Node.js ค้างไว้และรองรับ WebSocket (โฮสต์ PHP ทั่วไปหรือ serverless ใช้ไม่ได้)
- ตั้ง `PORT` ตามที่โฮสต์กำหนด มี `/healthz` สำหรับตรวจสถานะ
